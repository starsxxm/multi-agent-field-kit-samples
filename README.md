# Multi-Agent Field Kit — Free Samples

Two complete skills from the **Multi-Agent Field Kit**, free to use.

These are working procedures from a one-person, agent-run product operation — not course material and not a template dump. Each skill is a `SKILL.md` playbook you can load into AI coding assistants such as Claude Code or Codex.

## Free in this repo

1. **Demand Evidence Mining** (`demand-evidence-mining/`) — collect 20+ pieces of real, quotable demand (exact words, source link, current workaround, payment signal) before you write any code.
2. **Long-Task Checkpointing** (`long-task-checkpointing/`) — keep agent jobs alive across context limits and restarts with checkpoint files a fresh agent can resume from cold.

## The full kit (7 skills)

The complete pack adds five more procedures:

3. **Evidence-First Screening** — a kill-filter for ideas: if you can't name who does the job, how often, what it costs them, and how they cope today, it's noise.
4. **Cold Validation Outreach** — first contact with strangers who described the work: public-first, real identity, links only when asked.
5. **Cold Sender Seed Testing** — find out whether small legitimate batches land in inbox or spam, with decision rules written down *before* testing.
6. **Multi-Model Review Board** — one identical brief to several AI models, answered independently, reconciled by you.
7. **Subagent Research Briefing** — delegate research that comes back verifiable: self-contained briefs, source standards, and a raw re-check before you act on any summary.
